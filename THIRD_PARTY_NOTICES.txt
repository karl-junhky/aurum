sing-box
--------
Source: https://github.com/SagerNet/sing-box
License: GNU GPL version 3 or later.
Affory includes a Windows process-family extension. The corresponding source,
patch, build scripts and release fingerprint accompany each release.
See ustanovka/YADRO-ISHODNIKI.txt and ustanovka/GPL-3.0.txt.

vpn-uzel, the server program of "Свой VPN", links sing-box v1.14.2 as a
library and is distributed under GNU GPL version 3 or later. Its inbounds in
uzel/vhody are modified copies of sing-box protocol code. Its source is uzel/,
its quic-go dependency carries the same patch as the core. Build and
reproduction: ustanovka/UZEL-ISHODNIKI.txt.

Inter
-----
Designer: Rasmus Andersson.
Source: https://github.com/rsms/inter
License: SIL Open Font License 1.1.
Two woff2 subsets are bundled, Latin and Cyrillic, taken from the upstream
release without changes to glyph outlines.
Full license: cmd/affory-ui/frontend/src/shrifty/OFL-Inter.txt.

Service icons
-------------
Source: https://github.com/simple-icons/simple-icons/tree/15.0.0/icons
License: CC0 1.0.
Included marks: YouTube, Discord, OpenAI (ChatGPT), Instagram, Claude,
Telegram, Spotify, SoundCloud, Steam, Epic Games, Battle.net, Riot Games
and Ubisoft. SVG geometry is unchanged; the marks are
drawn as a CSS mask, so the interface, not the file, decides their colour.

Brand names and marks belong to their respective owners. These marks identify
routing destinations and do not imply endorsement.

OpenCCK service catalog
----------------------
Source: https://github.com/rekryt/iplist
License: MIT. See internal/katalog/LICENSE.opencck.
The selected domain suffixes and their source revisions are recorded in
internal/katalog/servisy.json.

HaGeZi DNS Blocklists
---------------------
Source: https://github.com/hagezi/dns-blocklists (adblock/light.txt, adblock/multi.txt)
License: GNU General Public License v3.0. See GPL-3.0.txt next to the program.
Included: a sing-box rule-set compiled from the "Multi LIGHT" list, embedded into
affory-svc.exe as the starting list (internal/reklama/vstroennyy-light.srs).
Its exact source text is internal/reklama/hagezi-light.txt; the list version is
recorded in internal/reklama/vstroennyy.json. At run time the service downloads
the current Multi LIGHT or NORMAL list from raw.githubusercontent.com and
converts it with the bundled sing-box.
